# Docs

## docs/ is the repo source of truth for specs

The repository docs are the source of truth: PRD, Architecture, ERD, ADR, and
all domain documents live in `docs/` as checked-in Markdown (see CLAUDE.md →
"Project Docs").

docs/ may only otherwise contain documentation required by the repo/tooling
itself (e.g. docs/LARAVEL_BOOST_GUIDELINES.md).
