# Git & Commit Rules

- **Format Commit Message:**
    - **Tipe & Judul Commit:** Wajib menggunakan Bahasa Inggris dengan standar Conventional Commits (contoh: `feat:`, `fix:`, `docs:`, `refactor:`, `style:`, `test:`, `chore:`).
    - **Deskripsi / Detail Tambahan (jika ada):** Dapat dituliskan dalam Bahasa Indonesia untuk memperjelas konteks perbaikan atau penambahan fitur.

    **Contoh Format Commit:**
    - `fix: bug login`
    - `feat: add user data scope filtering`
    - `docs: update installation steps in README`
    - `refactor: clean up organization service logic`
    - `fix: resolve Nginx reverse proxy header issue`
